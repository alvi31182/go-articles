# Статьи о Go на русском языке

Коллекция переведенных статей о конкурентном программировании в Go из проекта [Go 101](https://go101.org/) и официальной документации Go.

## 📚 Содержание

### Каналы

- **[Каналы в Go](channel-ru.md)**  
  Подробное объяснение типов каналов, их значений и всех концепций, связанных с каналами в Go. Рассматриваются внутренняя структура каналов и детали реализации стандартным компилятором/рантаймом Go.

- **[Случаи использования каналов в Go](channel-use-cases-ru.md)**  
  Множество практических примеров использования каналов: futures/promises, уведомления, передача данных, ограничение конкурентности, координация горутин, пулы воркеров и системы потоков данных.

- **[Как корректно закрывать каналы](channel-closing-ru.md)**  
  Подробное руководство по корректному закрытию каналов в различных сценариях: один отправитель, несколько отправителей, один получатель, несколько получателей и их комбинации. Рассматриваются принцип закрытия каналов и элегантные решения без использования panic/recover.

### Синхронизация конкурентности

- **[Модель памяти Go](memory-model-ru.md)**  
  Официальная спецификация модели памяти Go, определяющая условия, при которых чтение переменной в одной горутине может гарантированно наблюдать значения, записанные другой горутиной. Описывает синхронизацию через каналы, мьютексы и атомарные операции.

- **[Атомарные операции](atomic-operations-ru.md)**  
  Атомарные операции, предоставляемые в стандартном пакете `sync/atomic`. Рассматриваются атомарные операции для целых чисел, указателей и значений произвольных типов.

- **[Техники синхронизации из пакета `sync`](sync-package-ru.md)**  
  Техники синхронизации конкурентности из стандартного пакета `sync`: `WaitGroup`, `Once`, `Mutex`, `RWMutex` и `Cond`.

### Итераторы и расширения языка

- **[Range over function types в Go 1.23](range-over-function-types-ru.md)**  
  Подробно о новой поддержке `for range` по функциям, стандартных итераторах (`iter.Seq`, `iter.Seq2`), push/pull-подходах и свежих утилитах пакетов `iter`, `slices` и `maps`.

## 🎯 О проекте

Эти статьи представляют собой переводы материалов из проекта [Go 101](https://go101.org/), посвященные конкурентному программированию в Go. Все статьи переведены на русский язык, при этом примеры кода сохранены на английском, как в оригинале.

## 📖 Рекомендуемый порядок чтения

1. Начните с [Каналов в Go](channel-ru.md) для понимания основ
2. Изучите [Случаи использования каналов](channel-use-cases-ru.md) для практического применения
3. Изучите [Как корректно закрывать каналы](channel-closing-ru.md) для правильной работы с каналами
4. Изучите [Модель памяти Go](memory-model-ru.md) для глубокого понимания синхронизации
5. Узнайте об [Атомарных операциях](atomic-operations-ru.md) для низкоуровневых техник синхронизации
6. Изучите [Техники синхронизации из пакета `sync`](sync-package-ru.md) для дополнительных инструментов
